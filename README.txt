The App - family hub, full package
Upload everything in this folder to the site's root: index.html, manifest.json, service-worker.js, the icons folder and the apps folder (the four team apps).
Parents start with an empty app, add each child by choosing their team (or Other activity for any sport) and typing a first name. Everything they enter, including photos they scan, is saved only on their own device. Reading a photo uses the Tesseract text reader, which downloads from a public CDN the first time it is used.
